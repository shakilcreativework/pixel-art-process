01 — MODE SELECTION — DECIDE THIS FIRST

Ask:

Does the image have genuinely empty space around the subject that is intended to remain blank, or does the artwork fill the entire frame?

The artwork fills the entire canvas from edge to edge.

- Landscapes
- Full illustrated scenes
- Wallpapers
- Environments
- Scenes with sky, ground, water, buildings, or atmosphere reaching the canvas edges

The scene itself is the artwork.

MODE B — ISOLATED-ASSET

Use Mode B when the subject is intended to be isolated, cropped, exported, or have its background removed later.

- Characters
- Objects

26 — DESIGN-FIRST PIXEL PERFECTION CONTROL LAYER — v6
===============================================================================

THIS SECTION IS AN OVERRIDE-PRIORITY QUALITY LAYER.

The goal is NOT to make the artwork merely obey a grid.

The goal is to create the BEST POSSIBLE PIXEL-ART DESIGN while the grid,
pixel purity, isolation, and background rules remain fully enforced.

The final image must feel intentionally designed by a skilled pixel artist,
not generated first and forced into pixel rules afterward.

CORE PRINCIPLE

DESIGN QUALITY → RECOGNITION → SILHOUETTE → COMPOSITION → FORM →
COLOR HIERARCHY → LIGHTING → MATERIAL → MEANINGFUL DETAIL → PIXEL POLISH

Never reverse this order.

Do NOT begin by decorating the image with many small cells.

Build the design from its strongest visual idea first.

-------------------------------------------------------------------------------
26.1 — DESIGN INTENT LOCK
-------------------------------------------------------------------------------

Before constructing the artwork, mentally establish:

1. What is the exact subject?
2. What is the most recognizable feature?
3. What is the dominant silhouette?
4. What should the viewer notice first?
5. What supporting shapes are necessary?
6. What details can be removed without reducing recognition?
7. What visual mood or function should the design communicate?
8. Where should the strongest contrast occur?
9. Where should visual rest and negative space occur?
10. Which details are essential and which are optional?

If the answer to these questions is unclear, simplify the concept before adding
detail.

The artwork must communicate ONE clear primary visual idea.

Do not allow secondary details to compete with the main idea.

-------------------------------------------------------------------------------
26.2 — SILHOUETTE-FIRST CONSTRUCTION
-------------------------------------------------------------------------------

Construct the main subject in this order:

SILHOUETTE → MASS → PROPORTION → SECONDARY FORMS → INTERNAL FORMS →
LIGHTING → MATERIAL → ACCENTS

The silhouette must remain recognizable even if all internal colors and details
are temporarily removed.

The outer contour must have deliberate rhythm.

Avoid:

- Accidental bumps
- Random staircase changes
- Unnecessary contour noise
- Over-complicated corners
- Weak or ambiguous proportions
- Decorative contour marks with no structural purpose

If the silhouette is weak, DO NOT compensate with more internal detail.

Repair the silhouette first.

-------------------------------------------------------------------------------
26.3 — PIXEL CLUSTER GRAMMAR
-------------------------------------------------------------------------------

Treat groups of cells as intentional visual shapes, not isolated pixels.

Prefer:

- Connected masses
- Strong cluster boundaries
- Purposeful step patterns
- Consistent directional flow
- Clear light and shadow masses
- Controlled repeated motifs
- Deliberate negative-space cuts

Avoid:

- Random single-cell specks
- Checkerboard noise
- Equal-detail distribution everywhere
- Mechanical repetition
- Uncontrolled cell scattering
- Artificial texture density

Each cluster must have a readable reason to exist.

A strong cluster should describe FORM, MATERIAL, LIGHT, DEPTH, SILHOUETTE,
or MEANING.

If a cluster does none of these, remove it.

-------------------------------------------------------------------------------
26.4 — SHAPE LANGUAGE CONSISTENCY
-------------------------------------------------------------------------------

The entire artwork must use one coherent shape language.

Rounded subjects should use deliberate stepped curves.

Angular subjects should use deliberate structural corners.

Organic forms should use controlled irregularity.

Mechanical forms should use disciplined geometry.

Do not mix unrelated contour languages.

Do not make one object highly refined while another looks randomly blocked.

All major elements must feel as though they were designed by the same artist
using the same visual system.

-------------------------------------------------------------------------------
26.5 — PROPORTION AND RECOGNITION CHECK
-------------------------------------------------------------------------------

Before adding tertiary details, verify:

- Main subject proportions are believable for the requested concept.
- The most recognizable features are large enough to survive the grid.
- Important openings and separations remain visible.
- Major forms do not merge unintentionally.
- The subject is recognizable at thumbnail size.
- The focal feature is not hidden by decorative detail.

If a defining feature is too small for the fixed cell architecture:

SIMPLIFY → ENLARGE → MERGE → REPOSITION

Never create a smaller pixel.

-------------------------------------------------------------------------------
26.6 — FOCAL-POINT CONTRAST CONTROL
-------------------------------------------------------------------------------

The strongest visual contrast should normally support the primary focal point.

Do not distribute maximum contrast equally across the entire artwork.

Use controlled contrast through:

- Value
- Hue
- Saturation
- Shape
- Edge clarity
- Cluster density
- Lighting direction

Secondary areas should generally use simpler contrast relationships so that
the primary subject remains dominant.

Do not make every area equally loud.

-------------------------------------------------------------------------------
26.7 — PALETTE ECONOMY
-------------------------------------------------------------------------------

Use the smallest practical palette that communicates the design correctly.

Do not add a new color merely because a region feels empty.

Every palette color must have a role.

Typical roles may include:

- Background
- Main base
- Secondary base
- Shadow
- Deep shadow
- Highlight
- Accent
- Focal accent

Do not create near-duplicate colors that provide no meaningful improvement.

Prefer clear color relationships over excessive color count.

COLOR SHOULD DESCRIBE FORM, NOT DECORATE EMPTY SPACE.

-------------------------------------------------------------------------------
26.8 — VALUE STRUCTURE BEFORE COLOR DETAIL
-------------------------------------------------------------------------------

Before refining hue variation, establish a strong value hierarchy.

Verify that:

- The main subject separates from its surroundings.
- Major forms remain readable.
- Shadows actually describe depth.
- Highlights identify important surfaces.
- The focal point receives appropriate visual emphasis.

If the design does not read clearly in simplified value groups, do not solve
the problem by adding more colors.

Fix the value structure first.

-------------------------------------------------------------------------------
26.9 — LIGHTING LOGIC LOCK
-------------------------------------------------------------------------------

When lighting is present, establish ONE dominant lighting direction unless
the requested concept explicitly requires another arrangement.

All major highlights and shadows should agree with that lighting direction.

Do not place highlights randomly.

Do not place shadows merely because empty cells exist.

Lighting must explain:

- Plane direction
- Volume
- Depth
- Material
- Separation
- Focal hierarchy

Lighting complexity must never damage silhouette clarity.

-------------------------------------------------------------------------------
26.10 — DETAIL BUDGET
-------------------------------------------------------------------------------

Every artwork has a limited visual-detail budget.

Spend the budget in this order:

PRIMARY SUBJECT
→ DEFINING FEATURES
→ MAJOR SUPPORTING FORMS
→ MATERIAL INFORMATION
→ LIGHTING
→ SMALL ACCENTS

Do not spend the detail budget on:

- Random texture
- Empty-space decoration
- Repetitive noise
- Unrequested objects
- Tiny marks
- Redundant highlights
- Redundant shadows

A simpler image with stronger design is superior to a busier image with weaker
recognition.

-------------------------------------------------------------------------------
26.11 — NEGATIVE SPACE PROTECTION
-------------------------------------------------------------------------------

Negative space is an intentional design element.

Do not automatically fill empty areas.

Protect negative space when it:

- Separates objects
- Strengthens the silhouette
- Creates visual breathing room
- Directs attention
- Improves cropping
- Makes the subject easier to recognize

For isolated assets, preserve clean space around every independently usable
object.

Empty space is NOT unfinished detail.

-------------------------------------------------------------------------------
26.12 — EDGE RHYTHM AND CONTOUR QUALITY
-------------------------------------------------------------------------------

Every important contour should have deliberate staircase rhythm.

Avoid:

- Random 1-cell / 3-cell / 1-cell changes with no structural reason
- Jaggedness caused by careless placement
- Excessively repetitive stair patterns
- Unnecessary contour complexity

Use step patterns that communicate the intended geometry.

A curve should LOOK like a curve.

A diagonal should LOOK like a diagonal.

A corner should LOOK intentional.

The grid must serve the shape, not destroy the shape.

-------------------------------------------------------------------------------
26.13 — TANGENT AND MERGE PREVENTION
-------------------------------------------------------------------------------

Prevent accidental visual merges between unrelated forms.

Check for:

- Two silhouettes touching when they should be separate
- Background-colored gaps that accidentally split a single object
- Similar-value forms merging
- Decorative details touching focal contours
- Overlapping objects becoming one unreadable mass

If two forms unintentionally merge:

SEPARATE → SIMPLIFY → REPOSITION → REBUILD

Do not add random outlines to hide the problem.

-------------------------------------------------------------------------------
26.14 — REPETITION CONTROL
-------------------------------------------------------------------------------

Repeated elements must feel intentionally related but not mechanically copied.

For repeated leaves, stones, windows, tiles, stars, clouds, or similar forms:

- Preserve a common visual language.
- Vary arrangement when appropriate.
- Maintain consistent scale.
- Avoid random noise.
- Avoid identical copy-paste patterns unless repetition is conceptually required.

Variation must be meaningful, not arbitrary.

-------------------------------------------------------------------------------
26.15 — DEPTH READABILITY TEST
-------------------------------------------------------------------------------

Depth must remain readable without introducing smaller pixels.

Use:

- Overlap
- Scale
- Value
- Color temperature
- Atmospheric separation
- Cluster density
- Perspective
- Negative space

The foreground should not become visually indistinguishable from the
background.

Do not increase detail in distant objects simply because they feel empty.

Distance may reduce complexity while the 16×16 cell size remains identical.

-------------------------------------------------------------------------------
26.16 — THUMBNAIL RECOGNITION TEST
-------------------------------------------------------------------------------

The design must survive a quick visual glance.

Mentally inspect the artwork at a small preview size.
