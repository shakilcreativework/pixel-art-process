01 — MODE SELECTION (decide this first)

Ask: does the image have genuinely empty space around the subject, meant to be blank — or does the art fill the whole frame?

MODE A — FULL-SCENE
The artwork fills the entire canvas edge to edge (a landscape, a full illustrated scene, a wallpaper, anything with sky/ground/environment reaching all four sides).
→ Skip Section 02 entirely. The scene's sky/water/environment may use color variation and atmosphere, still built from discrete cell shading (see Section 09) — but there is no single-color background requirement, because the "background" IS the artwork.

→ Section 02 applies in full, zero tolerance.

Rule of thumb: if you would ever want to delete the background and keep only the subject → MODE B. If the "background" is itself the subject (sky, sunset, environment) → MODE A.

02 — BACKGROUND RULE (MODE B ONLY)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The background must be ONE single, uniform, solid color, edge to edge:

WHITE MODE: exactly #FFFFFF — RGB (255,255,255)
BLACK MODE: exactly #000000 — RGB (0,0,0)

Use exactly one. Never combine. Never invent a third background color. Not near-white, off-white, cream, warm/cool white, #FFFFFE/#FEFEFE/#FAFAFA; not near-black, charcoal, gray, blue-black, #010101/#020202/#050505; no gradient, vignette, texture, noise, transparency, or pattern in the background layer.

CRITICAL — NO BLEND, NO GLOW, NO SOFT EDGE TOUCHING THE BACKGROUND:
Every pixel in the image must be classifiable as EITHER exactly the background color OR a fully-opaque design color with clear separation from it. Never paint a soft glow, halo, drop-shadow, or partial-opacity blend that fades from the subject into the background — even a few "in-between" tiles (e.g. a dark olive tile that is part black, part yellow) are not acceptable. This is not a cosmetic rule: any pixel that sits color-between the subject and the background cannot be reliably classified by automated background-removal tools, and gets deleted along with the real background — destroying real design detail. If a glow or soft shadow is part of the concept, represent it as a fully opaque, complete-cell color band instead — never as a translucent blend into the background.

Edge integrity: no anti-aliased, semi-transparent, or blended pixels where subject meets background. No colored halos. The background color must sit clean immediately outside every object — a hard cell boundary, never a soft transition.

GLOW / LIGHT / SPARKLE EFFECTS (stars, magic effects, light bursts): build glow as 2–3 discrete, fully opaque concentric color rings — a bright core cell cluster, a mid-tone ring, a dim outer ring — each ring a single flat color occupying complete cells, with a hard edge between each ring and a hard edge to the background. NEVER use a smooth radial gradient or falloff that fades toward the background color. A "glow" that fades is indistinguishable from background contamination and will be deleted or corrupted by any downstream background-removal tool.

Asset-sheet specific (multiple objects, MODE B):
Every object shares the same background, same pixel-art language, same cell size. Keep clean negative space between objects — don't let them merge or decorate the gaps. Result should read as a professional, croppable asset sheet.
