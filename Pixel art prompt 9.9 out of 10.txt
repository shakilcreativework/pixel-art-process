============================================================
V10 — CELL-FIRST RENDERING PROTOCOL
============================================================

PRIMARY OBJECTIVE
============================================================

Create a true handcrafted pixel-art image using ONE
continuous global 16 × 16 pixel-cell lattice.

The artwork must be constructed CELL-FIRST.

Do NOT imagine a smooth illustration and then convert it
into pixels.

Do NOT create objects first and pixelate them afterward.

The entire image must be designed directly as an organized
collection of complete 16 × 16 cells.

The CELL is the fundamental building block.

The CELL is more important than the object.

The LATTICE is more important than realism.

STRUCTURAL CONSISTENCY is more important than tiny detail.

============================================================
ABSOLUTE MASTER CELL
============================================================

MASTER CELL = exactly 16 × 16 pixels.

This is the ONLY permitted geometric resolution.

There is exactly ONE master cell.

There is exactly ONE global lattice.

There is exactly ONE coordinate system.

There is exactly ONE pixel language.

No secondary resolution exists.

No local resolution exists.

No object-specific resolution exists.

No exception exists.

============================================================
CELL-FIRST CONSTRUCTION ORDER
============================================================

The artwork must conceptually be constructed in this order:

STEP 1
Establish the entire canvas as one continuous 16 × 16
master lattice.

STEP 2
Determine which complete cells are EMPTY and which
complete cells are OCCUPIED.

STEP 3
Assign one intentional color to each occupied cell.

STEP 4
Group neighboring cells into larger visual clusters.

STEP 5
Construct major silhouettes from those cell clusters.

STEP 6
Construct objects from the same cell clusters.

STEP 7
Create depth using cell density, color relationships,
layering and negative space.

STEP 8
Create lighting using neighboring cell colors.

STEP 9
Create texture only through intentional cell occupancy.

STEP 10
Remove every detail that cannot be represented by
complete cells on the same global lattice.

The image must remain cell-first from beginning to end.

============================================================
CELL OCCUPANCY MODEL
============================================================

Think of the image as a giant discrete occupancy map.

Each master cell has only two fundamental states:

EMPTY

or

OCCUPIED

An occupied cell contains one intentional color region.

A visual object is NOT a continuous shape.

A visual object is a collection of occupied cells.

A curve is a collection of occupied cells.

A diagonal is a collection of occupied cells.

A highlight is a collection of occupied cells.

A shadow is a collection of occupied cells.

A reflection is a collection of occupied cells.

A texture is a collection of occupied cells.

Everything is a cell arrangement.

============================================================
NO PARTIAL CELLS
============================================================

Every visible mark must occupy complete cells.

Never show a partial cell.

Never show a fragment of a cell.

Never show a tiny mark between cells.

Never show a line thinner than one complete cell.

Never show a geometric feature smaller than one complete
16 × 16 cell.

If a feature cannot fit inside one complete cell:

REMOVE IT.

If the feature is important:

REDESIGN IT USING A MULTI-CELL CLUSTER.

============================================================
NO INDEPENDENT OBJECT PIXEL GRIDS
============================================================

CRITICAL RULE:

Every object must use the SAME master lattice.

Do NOT create:

a small grid for flowers
a small grid for animal details
a small grid for clouds
a small grid for boats
a small grid for trees
a small grid for facial details
a small grid for textures

There is no object-specific pixel size.

There is no object-specific pixel density.

Objects receive more or fewer CELLS.

Objects NEVER receive smaller CELLS.

============================================================
SMALL OBJECT RULE
============================================================

A visually small object must NOT be rendered using tiny
pixels.

Instead:

SMALL OBJECT
→ FEWER COMPLETE CELLS.

Examples:

small flower
→ 1–4 intentional cells

small bird
→ small cluster of complete cells

small star
→ single or multi-cell cluster

small rock
→ compact cell cluster

small distant tree
→ fewer cells

small boat
→ fewer cells

Never:

small object
→ smaller pixels.

============================================================
LARGE OBJECT RULE
============================================================

Large objects receive MORE cells.

Examples:

large mountain
→ large cell mass

large tree
→ larger cell silhouette

large animal
→ more cell clusters

large house
→ more cell groups

large cloud
→ more occupied cells

Complexity comes from CELL COUNT and ARRANGEMENT.

Never from changing CELL SIZE.

============================================================
OBJECT SILHOUETTE FIRST
============================================================

For every important object:

FIRST create the silhouette using complete cells.

THEN create internal color clusters using complete cells.

THEN create shadows using complete cells.

THEN create highlights using complete cells.

NEVER begin with tiny internal details.

NEVER sacrifice the silhouette to create detail.

If internal detail conflicts with the silhouette:

KEEP THE SILHOUETTE.

============================================================
DETAIL HIERARCHY
============================================================

DETAIL must be represented by CELL COUNT.

Level 1:
single-cell detail.

Level 2:
two-cell cluster.

Level 3:
three-cell cluster.

Level 4:
four-cell cluster.

Level 5:
larger connected cluster.

Never create a new smaller resolution for higher detail.

HIGHER DETAIL
=
MORE INTELLIGENT CELL ARRANGEMENT.

NOT

SMALLER PIXELS.

============================================================
COLOR CELL RULE
============================================================

Each occupied cell should behave as a deliberate color unit.

No smooth gradient inside individual cells.

No soft color blending.

No interpolated edge colors.

No photographic transitions.

Use neighboring cells to create tonal transitions.

Example:

DARK CELL
→ MID CELL
→ LIGHT CELL

NOT:

DARK
→ smooth gradient
→ LIGHT

============================================================
REALISM CONTROL
============================================================

If realistic geometry conflicts with the master lattice:

SIMPLIFY THE GEOMETRY.

If a realistic detail requires smaller pixels:

REMOVE THE DETAIL.

If a realistic curve cannot be expressed with complete cells:

APPROXIMATE IT USING STEPPED CELL CLUSTERS.

If realistic texture requires micro-detail:

REPLACE IT WITH CELL-BASED PATTERNS.

Pixel architecture ALWAYS wins over realism.
