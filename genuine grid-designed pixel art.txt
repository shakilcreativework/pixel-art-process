03 — ABSOLUTE PIXEL ARCHITECTURE
==================================================

THE ENTIRE ARTWORK MUST USE ONE SINGLE 16×16 BASE CELL.

The 16×16 cell is the smallest possible visual unit.

ONE LOGICAL PIXEL = ONE COMPLETE 16×16 CELL.

Every visible design element must be constructed from complete cells or connected groups of complete cells.

This applies to:

- outlines
- silhouettes
- diagonals
- curves
- highlights
- shadows
- reflections
- texture
- windows
- leaves
- petals
- eyes
- facial features
- architectural elements
- rocks
- clouds
- water
- environmental details

NEVER subdivide a 16×16 cell.

NEVER create a smaller pixel.

NEVER introduce a second pixel scale.

NEVER use micro-pixels.

NEVER use sub-pixel geometry.

NEVER use fractional geometry.

The entire image must appear as though it was designed from the beginning on one invisible 16×16 lattice.

05 — AUTHENTIC PIXEL CONSTRUCTION
==================================================

The artwork must look like it was manually designed pixel-by-pixel.

It must NOT look like:

- a smooth illustration converted into pixels
- a photograph with pixelation
- vector artwork with square edges
- AI artwork with pixel texture
- a digital painting with a pixel filter

Every shape must be intentionally constructed from discrete cells.

Avoid random jagged edges.

Every staircase must look designed.

Every diagonal must have intentional rhythm.

Every curve must use controlled stepped geometry.

Use patterns such as:

1-cell step
1-cell step
2-cell step
2-cell step

or other intentional staircase structures.

Never smooth the staircase with smaller pixels.
