01 — ABSOLUTE PIXEL ARCHITECTURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The entire artwork MUST be conceptually constructed on one single,
uniform, immutable 16×16 base-cell lattice.

16×16 is the smallest permitted geometric unit anywhere in the artwork.

This is NOT merely a pixel-art visual style.

This is a CELL-CONSTRUCTION RULE.

Every visible form, object, contour, highlight, shadow, texture,
reflection, pattern, character feature, environmental detail and
decorative element must be represented through complete 16×16 cells
or larger integer combinations of those cells.

VALID UNIT SIZES:

16×16
32×16
16×32
32×32
48×16
16×48
48×32
32×48
64×16
16×64
64×32
32×64
64×64
and larger integer combinations of the same 16×16 base cell.

NEVER introduce a geometric unit smaller than one complete 16×16 cell.

02 — CELL OCCUPANCY LOGIC
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Think of the entire image as a giant grid of discrete cells.

Each cell is either:

• EMPTY
or
• OCCUPIED

An occupied region must contain complete cell units.

Shapes are created by combining neighboring occupied cells.

Do NOT draw continuous sub-cell geometry and then make it look pixelated.

Instead:

SHAPE → CELL OCCUPANCY → CELL CLUSTER → FINAL FORM

Every contour must be the result of adding or removing complete cells.

Diagonal forms must be created with stepped cell clusters.

Curves must be created with stepped cell clusters.

Thin forms must become wider cell structures.

Tiny details must become simplified cell symbols.

If a visual detail cannot exist using complete 16×16 cells:

SIMPLIFY IT.

DO NOT SHRINK THE CELL.

DO NOT INTRODUCE A SMALLER PIXEL.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
03 — ABSOLUTE CELL SIZE INVARIANCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CELL SIZE NEVER CHANGES.

Do not create:

micro-pixels
mini-pixels
sub-pixels
half-cells
quarter-cells
fractional cells
thin pixel lines
single-pixel outlines
sub-cell texture
sub-cell highlights
sub-cell shadows
sub-cell anti-aliasing
sub-cell noise

NO DETAIL IS ALLOWED TO CAUSE CELL SIZE REDUCTION.

More detail may be created ONLY by increasing the number of occupied
16×16 cells.

DETAIL DENSITY may change.

CELL SIZE may NOT change.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
04 — NO SUB-CELL GEOMETRY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

This rule has absolute priority.

NEVER use a thin line merely because the real-world object is thin.

For example:

Rope → stepped 16×16 cell chain
Wire → stepped 16×16 cell chain
Grass blade → stepped 16×16 cell cluster
Hair → grouped cell cluster
Sword edge → complete-cell stepped contour
Propeller → complete-cell stepped blades
Branch → complete-cell stepped structure
Fence → complete-cell stepped structure
Small architectural trim → simplified cell blocks
Tiny facial feature → simplified cell symbol
Tiny text-like marking → simplified cell pattern
Reflection → complete-cell horizontal/stepped clusters

If the object would require a line thinner than 16×16:

DO NOT DRAW THE THIN LINE.

Convert it into the closest readable 16×16 cell structure.

Readability is achieved through CELL ARRANGEMENT,
not through smaller geometry.

05 — OUTLINE ARCHITECTURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Do not use arbitrary thin outlines.

Outlines must also obey the 16×16 architecture.

Use:

single-cell borders
double-cell borders
stepped-cell contours
larger clustered borders

depending on the scale of the object.

At small scale, merge outline and object cells when necessary.

Never create a sub-cell outline around a shape.

A clean silhouette is more important than microscopic outlining.

06 — HIERARCHICAL CELL QUANTIZATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Use hierarchical cell density WITHOUT changing cell size.

BACKGROUND:
Low occupied-cell density.
Large simplified forms.
Minimal texture.

MIDDLE GROUND:
Moderate occupied-cell density.
Readable secondary objects.
Controlled environmental detail.

FOREGROUND:
Higher occupied-cell density.
Strong silhouettes.
More complete-cell clusters.
More visual information.

PRIMARY SUBJECT:
Highest intentional cell density where needed.

IMPORTANT:

HIGHER DETAIL = MORE CELLS.

NOT:

HIGHER DETAIL = SMALLER CELLS.

Never escalate detail by introducing finer pixels.

15 — MICRO-DETAIL REPLACEMENT RULE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

This is a critical rule.

When the design concept contains a detail smaller than one 16×16 cell:

STEP 1:
Identify the detail.

STEP 2:
Determine whether it can be represented by one or more complete cells.

STEP 3:
If yes, represent it with complete cells.

STEP 4:
If no, simplify or remove it.

NEVER:

shrink the cell
add a smaller pixel
draw a thin line
use anti-aliasing
use fractional geometry

SIMPLIFICATION IS REQUIRED.

CELL PURITY ALWAYS WINS OVER MICRO-DETAIL.
